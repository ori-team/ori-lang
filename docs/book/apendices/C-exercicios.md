# Apêndice C — Exercícios

> Soluções sugeridas em [`../exercicios/`](../exercicios/).  
> Use `ori check` / `ori run` em cada um.

1. **Hello pessoal** — Imprima seu nome com `f"…"`. (Caps 10–11)
2. **Soma tipada** — Função `add(a: int, b: int) -> int`. (Cap. 14)
3. **Divisão segura** — `divide` retorna `result[int, string]`; trate com `match`. (Cap. 12)
4. **Optional** — `find` retorna `optional[string]`; use `if some(x) = …`. (Cap. 12)
5. **Pipe** — Encadeie duas funções com `|>`. (Cap. 13)
6. **Struct Point** — Literal + print dos campos. (Cap. 14)
7. **Dois módulos** — `greeter` + `main` no mesmo projeto. (Cap. 15)
8. **Displayable** — `apply` + `use core.Displayable` e `string(p)`. (Cap. 16)
9. **Ler arquivo** — `fs.read_text` + `try` em `main() -> result[…]`. (Cap. 17)
10. **Teste** — Um `ori.test` assert simples (ver `examples/tests_demo`). (Cap. 17)
11. **CLI args** — Leia um argumento e imprima (ver `examples/cli_args`). (Caps 11, 19)
12. **Diagnostic** — Provocar `name.undefined` de propósito e ler o código. (Cap. 21)
